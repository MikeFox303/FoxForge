# FoxForge v0.1.0-alpha.4.1

First hotfix for `alpha.4`, focused on responsive interface stability.

## Fixed

- Operator access is compact by default and no longer covers workspace content.
- Lock remains directly reachable after write access is unlocked.
- Add Printer stays in the responsive topbar flow.
- Narrow-phone sidebar no longer stretches with page content.
- Phone navigation remains compact and respects the iOS bottom safe area.
- Narrow/tablet layouts avoid document-level horizontal overflow.
- 32:9 layouts keep product content bounded and centered.
- Inventory browser tests correctly open compact operator access before entering the command token.

## Validation

Playwright covers phone 390x844 (DPR3/touch), tablet 900x1024, desktop 1920x1080, and desktop 5120x1440. PR #97 passed the production-container browser suite with 57 passed, 3 skipped and 0 failed, together with Web UI, container, security and deployment-authentication gates.

The release identity also validates the `alpha.N.M` hotfix format and keeps the frontend package lock synchronized with `0.1.0-alpha.4.1`.

## Upgrade notes

No persistence schema change is introduced. Back up `/data` before updating. The Umbrel package must be updated only after the guarded release workflow publishes and verifies the immutable multi-architecture image digest.
